El lenguaje de la Web

Aprender la sintaxis de HTML es un paso muy importante en el desarrollo web.

Para ello, debemos entender que significa HTML.

También es necesario conocer la etiqueta, que sirve para estructurar el contenido.

Como indica la documentación oficial: HTML es el código que se utiliza para estructurar y desplegar una página web y sus contenidos

Es fundamental escribir el código de forma ordenada, tal como se muestra en este bloque

    body {
        background-color: white;
    }
